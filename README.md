# Art Ton

Многостраничный сайт Art Ton для услуг в Заречном, Пензе и Пензенской области.

## Стек

- Vue 3.5, Composition API, TypeScript strict
- Vite 8, Vite SSG, Vue Router
- Pinia, vue-i18n, Unhead
- Vitest, ESLint flat config, Prettier
- Cloudflare Worker API, D1 и R2

## Команды

```bash
npm run dev
npm run check
npm run build
```

## Бесплатный хостинг

Проект рассчитан на Cloudflare Workers Free:

- публичные страницы собираются в статический HTML;
- Worker обслуживает API, sitemap, robots и SEO-метаданные;
- D1 хранит заявки, настройки и цены;
- R2 хранит новые фотографии портфолио;
- заявки дополнительно отправляются в Telegram.

## Защищённые настройки

Скопируйте `.env.example` в локальный `.env` и заполните значения. Файл `.env` не
попадает в Git.

- `ADMIN_USERNAME` — отдельный логин администратора;
- `ADMIN_PASSWORD_HASH` — PBKDF2-хеш, создаётся командой `npm run password:hash`;
- `SESSION_SECRET` — длинная случайная строка для подписи сессий;
- `TELEGRAM_BOT_TOKEN` — токен бота Telegram;
- `TELEGRAM_CHAT_ID` — идентификатор чата для заявок.

Пароль, токен Telegram и секрет сессии нельзя добавлять в исходный код или отправлять
в публичный репозиторий.

## Архитектурные принципы

- Публичные страницы генерируются в HTML для скорости и индексации.
- Контактные данные и варианты заявок хранятся централизованно.
- D1 является источником истины для редактируемого контента и заявок, R2 — для фотографий.
- Pinia хранит только клиентское состояние интерфейса и временный локальный черновик.
- Запись на замер используется только для потолков; тонировка начинается с консультации.
- В админке можно менять факты о компании, цены и статусы заявок.
